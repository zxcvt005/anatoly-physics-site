# Юридические документы (PDF)

Положите PDF от юриста в эту папку с **точными** именами:

| Файл на диске | Документ |
|---------------|----------|
| `offer.pdf` | Договор-оферта |
| `privacy-policy.pdf` | Политика обработки персональных данных |
| `personal-data-consent.pdf` | Согласие на обработку персональных данных |
| `marketing-consent.pdf` | Согласие на рекламную рассылку |

После замены документа обновите поле `version` в `src/lib/legal/documents.ts`.

Старые пути `/documents/oferta.pdf` и `/oferta.pdf` перенаправляются на `/documents/offer.pdf`.
